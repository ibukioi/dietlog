# ADR 0001: Next.js の Cache Components を使わない

- 日付: 2026-11-22
- 状態: 採用

## 背景

create-next-app(Next.js 16.4)の初期設定では `cacheComponents: true` になっている。Cache Components ではリクエスト時のデータ(Cookie・セッション)を読む部分をすべて `<Suspense>` の内側に置く必要があり、読まない部分は静的シェルとしてプリレンダリングされる。

## 判断

このアプリはランディングと `/about` 以外のすべての画面が、ログイン中のユーザー(お試しユーザーを含む)の記録を表示する動的ページで、静的シェルとして共有できる部分がほとんどない。Cache Components を有効にしても得られる効果が小さく、セッションを読む箇所ごとに境界を設計するコストが大きいため、無効にして従来のレンダリング(`dynamic = "force-dynamic"` の画面単位)とする。

## 影響

- 画面ごとのデータ取得は Server Component で素直に書ける。
- 将来、公開ページ(ランディング等)を増やす場合は再検討する。
