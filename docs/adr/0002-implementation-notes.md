# ADR 0002: 設計書 v0.5 からの実装上の判断

- 日付: 2026-11-22
- 状態: 採用

設計書(`docs/architecture.md` v0.5)どおりに実装したうえで、実装中に判明した事実に合わせて次の判断をした。

1. **ビタミンB12 は目安量(AI)として扱う** — 食事摂取基準 2025年版では B12 は推定平均必要量・推奨量ではなく目安量。§5.2 の「EAR/RDA 系」から外れるが、判定の種類は `data/dri/dri-2025.json` の指標から自動で決まる。
2. **鉄の基準値のためにプロフィールに「月経の有無」を追加** — 女性 18〜64 歳の鉄は月経あり/なしで基準値が異なる。
3. **身体活動レベルは「低い/ふつう/高い」** — 2025年版の表記。DB の値は I/II/III のまま。推定エネルギー必要量は「体重1kg当たりの推定エネルギー必要量(参考表1)× 体重」で個人の体重を反映する。
4. **1 品の中の不明値の許容(5%)** — 1 品(自炊のレシピ)の中で、ある成分の値が不明な食材のエネルギーが全体の 5% 以下なら既知値の合計を採用する(例: だしに食物繊維の記載がなくても味噌汁全体を不明にしない)。5% を超えると不明(null)。§4.3 の「不明を 0 として黙って足さない」は維持。
5. **分析の平均は、データのない食品の分をエネルギー比で補う** — カバレッジ 80% 以上で判定する際、不明分を 0 として平均すると実際より少なく見積もり「不足」に偏る。`平均 = 既知値の合計 / 記録日数 / カバレッジ` とし、画面に補正前の値も表示する。
6. **調理後データがない場合の後備係数** — 表13・14 の転記ではなく、表12 の重量変化率と成分表の調理前後の脂質から、調理法 × 食品群の中央値を算出した(`data/mext/cooking-coefficients.json`)。炒め物の全体中央値は吸油量 3.6 g/生100 g で、表14 の条件(生100 g に油 5 g)と整合する。
7. **お試しのサンプルは過去 6 日分 + 今日の朝食** — 6 日とも記録日の条件を満たすため、開始直後から分析を見られる(§8.1 の「夕食を記録すれば見られる」より早い)。面接官がすぐに分析を確認できることを優先した。
8. **OFF の人気語ウォームアップは手動スクリプト** — `pnpm data:warm-off`。レート制限が厳しく(実測で約 4 回/分でも 503)、ビルドやデプロイのたびに実行するのは避ける。
