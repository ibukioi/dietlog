# data/

アプリが使う参照データと、その出典・加工方法です。

| パス | 内容 | 出典 | 作り方 |
|---|---|---|---|
| `mext/foods.json` | 2,538 食品 × 成分識別子(収載値の原文表記) | 日本食品標準成分表（八訂）増補2023年 第2章(データ)Excel、更新日 2026年3月27日 | `pnpm data:download && pnpm data:build` |
| `mext/meta.json` | 取り込み元のURL・SHA-256、正誤表との照合結果 | 同上 + 正誤表(データ) 令和8年3月27日 | 同上 |
| `mext/cooked-variants.json` | 生食品 × 調理法 → 調理後食品・重量変化率 | 同 第1章 表12 | `manual/table12_weight_change.csv` と食品名の対応から生成 |
| `mext/cooking-coefficients.json` | 調理法 × 食品群の後備係数(重量変化率・吸油量の中央値) | 表12 と調理前後の脂質から算出 | `pnpm data:build` |
| `mext/retention-factors.json` | 調理法 × 食品群 × 成分の残存率(ビタミン・ミネラル、中央値) | 表12 の重量変化率と調理前後の成分値から算出 | `pnpm data:retention` |
| `manual/table12_weight_change.csv` | 表12 の食品番号ごとの重量変化率(509 件) | 同 電子書籍PDF 第1章 表12 | `scripts/data/extract_table12.py`(列の x 座標で抽出する転記補助) |
| `manual/aliases.json` | 検索用の同義語辞書(「鶏むね」→「にわとり むね」など) | 手作業 | — |
| `manual/popular.json` | 検索で上位に出すよく使う食品 | 手作業 | — |
| `dri/dri-2025.json` | 成人の食事摂取基準(EAR・RDA・AI・DG・UL)、推定エネルギー必要量、PFC バランス | 厚生労働省「日本人の食事摂取基準（2025年版）」策定検討会報告書(正誤表 令和7年3月25日 確認済み) | 報告書の各表から手作業で転記(PDF の文字情報が壊れているため画像で確認) |
| `seed/guest-template.json` | お試しモードのサンプルデータ | 本プロジェクト作成(市販品は特定商品ではないサンプル値) | — |

## 出典表記

- 食品成分値: **日本食品標準成分表（八訂）増補2023年から引用**(文部科学省)。文部科学省は二次利用の許諾手続きを不要とし、出典の明示を求めています。
- 食事摂取基準: 厚生労働省「日本人の食事摂取基準（2025年版）」
- 食品成分データベース(fooddb.mext.go.jp)の画面からはデータを取得していません。

## 確認済みの事項(2026-11-22)

- 本表 Excel(2026-03-27 版)には正誤表の訂正が反映済み。`data:build` は正誤表の「正」値 307 項目と照合し、すべて一致(上書き 0 件)。
- 表12 の重量変化率 509 件のうち 394 件を、食品名から生食品と対応づけた(対応できないもの 1 件: 角形食パン 焼き)。
- 2025年版ではビタミンB12 が目安量(AI)になっているため、判定は「目安量を下回っている」の扱いになる。
